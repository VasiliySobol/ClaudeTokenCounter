
특정 규칙에 따라 PDF 파일의 이름을 변경하는 소규모 WPF 도구를 위한 XAML 마크업이 필요합니다. PDF 파일은 ZIP 아카이브 형태나 개별 파일 형태로 제공될 수 있습니다. 파일 제공 방식은 다음 두 가지를 지원해야 합니다. 1. 사용자가 파일 탐색기를 통해 ZIP 아카이브나 PDF 파일을 직접 선택할 수 있어야 합니다. 이를 위해 선택된 입력 경로를 표시하는 텍스트 상자와, 파일 탐색기를 열어 입력 경로를 변경할 수 있는 버튼이 UI에 포함되어야 합니다. 2. 사용자가 드래그 앤 드롭 방식으로 ZIP 아카이브나 PDF 파일을 제공할 수 있어야 합니다. 이를 위해 UI에는 넓은 '드래그 앤 드롭' 영역이 포함되어야 합니다. 또한, 이름이 변경된 PDF 파일이 저장될 출력 경로를 표시하는 텍스트 상자도 필요합니다. 이 경로에는 기본값이 미리 설정되어 있어야 하며, 사용자가 별도의 버튼을 클릭하여 파일 탐색기에서 새로운 출력 위치를 선택함으로써 이를 변경할 수 있어야 합니다. 아울러 기본 이름 변경 규칙(예: `YYYY.MM %New file name%`)을 표시하는 텍스트 상자도 있어야 합니다. 여기서 '새 파일 이름(New file name)'은 UI 수준이 아닌 비즈니스 로직에 의해 결정됩니다. ZIP 아카이브나 PDF 파일이 제공되고, 출력 폴더가 선택되며, 이름 변경 규칙이 설정되면, 각 파일의 이전 이름과 새로운 이름을 보여주는 구성 요소가 UI에 나타나야 합니다(표 형태가 아닌, 더 현대적이고 시각적으로 매력적인 방식이어야 합니다). 이 목록은 새로운 아카이브가 제공되거나 개별 PDF 파일이 추가 또는 삭제될 때마다 업데이트되어야 합니다. 또한 두 개의 체크박스가 필요합니다. 1) 첫 번째 체크박스는 작업 완료 후 원본 ZIP 아카이브나 소스 파일을 삭제할지 여부를 결정합니다. 2) 두 번째 체크박스는 출력 디렉토리 내에 별도의 폴더를 생성할지 여부를 결정합니다. 마지막으로, 이름 변경 프로세스를 시작하는 버튼이 포함되어야 합니다.
