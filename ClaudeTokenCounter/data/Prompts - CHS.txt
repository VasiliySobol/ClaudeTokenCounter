
我需要为一个小型 WPF 工具编写 XAML 标记代码，该工具旨在根据特定模式重命名 PDF 文件。输入源可以是 ZIP 压缩包，也可以是独立的 PDF 文件。程序应支持两种输入方式：1. 用户可通过“文件资源管理器”选择 ZIP 压缩包或 PDF 文件。为此，界面需包含一个用于显示所选输入路径的文本框，以及一个允许用户通过“文件资源管理器”浏览并更改输入路径的按钮。2. 用户也可以通过拖放操作提供 ZIP 压缩包或 PDF 文件；界面中应设置一个较大的“拖放区域”以实现此功能。此外，界面还需包含一个文本框，用于指定重命名后 PDF 文件的输出路径。该路径应预设一个默认值，同时允许用户点击专用按钮，通过“文件资源管理器”选择新的输出位置。界面中还应设有一个文本框，用于显示默认的重命名模式（例如：`YYYY.MM %New file name%`）；其中，“新文件名”部分由业务逻辑决定，而非在 UI 层处理。在用户提供了 ZIP 压缩包或 PDF 文件、选定了输出文件夹并设置好重命名模式后，界面应展示一个组件（不应是传统的表格，而应采用更现代、视觉效果更佳的呈现方式），列出每个文件的原名称及新名称。当导入新的压缩包，或添加/移除 PDF 文件时，该列表应自动更新。此外，界面还应包含两个复选框：1) 第一个复选框用于决定处理完成后是否删除原始 ZIP 压缩包或源文件；2) 第二个复选框用于决定是否在输出目录下创建一个独立的子文件夹。最后，界面上应设有一个按钮，用于启动重命名流程。
