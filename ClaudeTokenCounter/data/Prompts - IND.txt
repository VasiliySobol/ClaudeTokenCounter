
Saya memerlukan markup XAML untuk aplikasi WPF sederhana yang berfungsi mengganti nama file PDF berdasarkan pola tertentu. File PDF dapat disediakan dalam bentuk arsip ZIP atau sebagai file-file terpisah. Terdapat dua cara untuk memasukkan file: 1. Pengguna dapat memilih arsip ZIP atau file PDF secara langsung melalui File Explorer. Untuk itu, antarmuka pengguna (UI) harus menyertakan kotak teks yang menampilkan jalur (path) input yang dipilih, serta tombol untuk menelusuri dan mengubah jalur input tersebut melalui File Explorer. 2. Pengguna dapat memasukkan arsip ZIP atau file PDF melalui metode *drag and drop* (seret dan lepas); untuk keperluan ini, UI harus menyediakan area *drag and drop* yang cukup luas. UI juga harus memiliki kotak teks untuk menentukan jalur output (lokasi penyimpanan) bagi file PDF yang telah diganti namanya. Jalur ini akan memiliki nilai *default* yang sudah ditetapkan, namun pengguna dapat mengubahnya dengan mengeklik tombol khusus dan memilih lokasi output baru melalui File Explorer. Selain itu, tersedia kotak teks untuk pola penggantian nama (*renaming pattern*) *default*, contohnya: `YYYY.MM %New file name%`, di mana nama file baru akan ditentukan oleh logika bisnis, bukan pada tingkat UI. Setelah arsip ZIP atau file PDF dimasukkan, folder output dipilih, dan pola penggantian nama ditetapkan, UI akan menampilkan komponen (bukan berupa tabel, melainkan sesuatu yang lebih modern dan menarik secara visual) yang memperlihatkan nama lama dan nama baru untuk setiap file. Daftar ini akan diperbarui setiap kali arsip baru dimasukkan, atau saat file PDF ditambahkan maupun dihapus. Terdapat pula dua kotak centang (*checkbox*): 1) Kotak centang pertama untuk menentukan apakah arsip ZIP asli atau file sumber harus dihapus setelah proses selesai. 2) Kotak centang kedua untuk menentukan apakah folder terpisah perlu dibuat di dalam direktori output. Terakhir, harus ada tombol untuk memulai proses penggantian nama.

Tolong carikan penerbangan berangkat pada tanggal 20 dari lokasi saya, dan penerbangan kembali dari Praha pada tanggal 27. Pilih opsi yang memberikan nilai terbaik untuk harganya.
