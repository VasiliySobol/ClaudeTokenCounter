
ฉันต้องการ XAML markup สำหรับเครื่องมือ WPF ขนาดเล็กที่ทำหน้าที่เปลี่ยนชื่อไฟล์ PDF ตามรูปแบบที่กำหนด โดยไฟล์ PDF สามารถนำเข้าได้ทั้งในรูปแบบไฟล์ ZIP หรือไฟล์ PDF แยกแต่ละไฟล์ ซึ่งรองรับวิธีการนำเข้า 2 รูปแบบ ได้แก่ 1. ผู้ใช้สามารถเลือกไฟล์ ZIP หรือไฟล์ PDF ผ่าน File Explorer ได้ โดยในส่วนติดต่อผู้ใช้ (UI) จะต้องมีช่องข้อความ (Text Box) สำหรับแสดงพาธของไฟล์ที่เลือก และปุ่มสำหรับเรียกดูและเปลี่ยนพาธผ่าน File Explorer 2. ผู้ใช้สามารถนำเข้าไฟล์ ZIP หรือไฟล์ PDF ด้วยวิธีลากและวาง (Drag & Drop) โดยต้องมีพื้นที่ขนาดใหญ่สำหรับรองรับการลากและวางไฟล์ นอกจากนี้ UI ควรมีช่องข้อความสำหรับระบุพาธปลายทาง (Output Path) ที่จะบันทึกไฟล์ PDF ที่เปลี่ยนชื่อแล้ว โดยจะมีค่าเริ่มต้นที่กำหนดไว้ตายตัว แต่ผู้ใช้สามารถเปลี่ยนพาธได้โดยการกดปุ่มเฉพาะเพื่อเลือกตำแหน่งใหม่ผ่าน File Explorer อีกทั้งยังมีช่องข้อความสำหรับกำหนดรูปแบบการเปลี่ยนชื่อไฟล์ (Renaming Pattern) เช่น `YYYY.MM %New file name%` (โดยที่ชื่อไฟล์ใหม่จะถูกกำหนดด้วยตรรกะทางธุรกิจ ไม่ใช่กำหนดจากส่วน UI) เมื่อมีการนำเข้าไฟล์ ZIP หรือไฟล์ PDF, เลือกพาธปลายทาง และกำหนดรูปแบบการเปลี่ยนชื่อไฟล์เรียบร้อยแล้ว UI จะต้องแสดงส่วนประกอบ (ไม่ใช่ในรูปแบบตาราง แต่เป็นรูปแบบที่ดูทันสมัยและสวยงามกว่า) เพื่อแสดงชื่อไฟล์เดิมและชื่อไฟล์ใหม่ของแต่ละไฟล์ โดยรายการนี้จะอัปเดตอัตโนมัติเมื่อมีการนำเข้าไฟล์ ZIP ใหม่ หรือมีการเพิ่ม/ลบไฟล์ PDF นอกจากนี้ยังมีช่องทำเครื่องหมาย (Checkbox) 2 รายการ ได้แก่ 1) ช่องสำหรับเลือกว่าต้องการลบไฟล์ ZIP ต้นฉบับหรือไฟล์ต้นทางทิ้งหลังจากประมวลผลเสร็จสิ้นหรือไม่ และ 2) ช่องสำหรับเลือกว่าต้องการสร้างโฟลเดอร์แยกต่างหากภายในไดเรกทอรีปลายทางหรือไม่ สุดท้ายจะต้องมีปุ่มสำหรับเริ่มกระบวนการเปลี่ยนชื่อไฟล์

อลิซเริ่มรู้สึกเบื่อหน่ายเต็มทีกับการนั่งอยู่ข้างพี่สาวบนริมตลิ่งโดยไม่มีอะไรทำ เธอแอบชำเลืองมองหนังสือที่พี่สาวกำลังอ่านอยู่บ้างเป็นครั้งคราว แต่ในหนังสือนั้นไม่มีทั้งภาพประกอบหรือบทสนทนาใดๆ เลย "แล้วหนังสือที่ไม่มีภาพหรือบทสนทนาจะมีประโยชน์อะไรกันล่ะ" อลิซคิดในใจ (เท่าที่สมองอันง่วงงุนและมึนตื้อจากอากาศร้อนจัดจะพอคิดได้) ขณะกำลังชั่งใจว่าการลุกขึ้นไปเก็บดอกเดซีมาร้อยเป็นพวงนั้นคุ้มกับความเหนื่อยยากหรือไม่ ทันใดนั้น กระต่ายขาวตัวหนึ่งที่มีดวงตาสีชมพูก็วิ่งผ่านหน้าเธอไป แม้เรื่องนี้จะไม่ได้ดูแปลกประหลาดอะไรนัก และอลิซเองก็ไม่ได้รู้สึกแปลกใจเท่าไรที่ได้ยินเจ้ากระต่ายพึมพำกับตัวเองว่า "แย่แล้ว! แย่แล้ว! ฉันต้องไปสายแน่ๆ!" (ซึ่งเมื่อมานึกย้อนดูภายหลัง เธอก็คิดว่าตัวเองน่าจะแปลกใจกับเรื่องนี้ แต่ในตอนนั้นทุกอย่างกลับดูเป็นเรื่องปกติธรรมดาไปเสียหมด) ทว่าเมื่อเจ้ากระต่ายหยิบนาฬิกาพกออกมาจากกระเป๋าเสื้อกั๊ก ดูเวลาแล้วรีบวิ่งต่อไป อลิซก็ลุกพรวดขึ้นทันที เพราะเพิ่งฉุกคิดได้ว่าไม่เคยเห็นกระต่ายตัวไหนมีกระเป๋าเสื้อกั๊กหรือมีนาฬิกาพกมาก่อน ด้วยความอยากรู้อยากเห็นอย่างเต็มเปี่ยม เธอจึงวิ่งไล่ตามมันไปกลางทุ่ง และโชคดีที่ทันเห็นมันมุดหายเข้าไปในโพรงกระต่ายขนาดใหญ่ใต้แนวพุ่มไม้ อลิซไม่รอช้า รีบมุดตามลงไปทันทีโดยไม่ได้นึกเลยสักนิดว่าจะกลับขึ้นมาได้อย่างไร โพรงนั้นทอดยาวเข้าไปข้างในคล้ายอุโมงค์อยู่ช่วงหนึ่ง ก่อนจะลาดดิ่งลงไปอย่างกะทันหัน รวดเร็วเสียจนอลิซไม่ทันได้ตั้งตัวหยุดยั้ง ก่อนที่เธอจะพบว่าตัวเองกำลังร่วงหล่นลงไปในหลุมที่ลึกมากแห่งหนึ่ง

สวัสดีครับ ผมวางแผนจะไปเที่ยวกรุงปรากเป็นเวลาหนึ่งสัปดาห์ในช่วงเทศกาลคริสต์มาสที่จะถึงนี้ รบกวนช่วยวางแผนการเดินทางให้หน่อยได้ไหมครับ? ช่วยหาเที่ยวบินขาไปในวันที่ 20 ธันวาคม และเที่ยวบินขากลับจากกรุงปรากในวันที่ 27 ธันวาคม โดยเลือกตัวเลือกที่คุ้มค่าที่สุดให้ด้วยครับ นอกจากนี้ ช่วยหาโรงแรมระดับ 4 ดาวที่อยู่ใกล้ใจกลางเมืองให้หน่อยครับ ผมควรเดินทางจากสนามบินไปยังโรงแรมอย่างไร และควรใช้การเดินทางแบบไหนในการท่องเที่ยวภายในเมือง? ช่วยแนะนำสถานที่ท่องเที่ยวและจัดตารางเวลาในแต่ละวันให้ด้วยครับ รวมถึงช่วยแนะนำร้านอาหารที่น่าไปและร้านที่ควรหลีกเลี่ยง โดยเฉพาะร้านที่เกี่ยวกับเบียร์หรือโรงเบียร์ต่างๆ ครับ นอกจากนี้ อยากทราบว่ามีอาหารท้องถิ่นอะไรที่ควรลองบ้าง และโดยรวมแล้วอาหารเช็กมีลักษณะเป็นอย่างไร? ค่าใช้จ่ายต่างๆ ในเมือง เช่น ค่าเข้าชมพิพิธภัณฑ์ นิทรรศการ หรือการเดินตลาดเป็นอย่างไรบ้างครับ? ควรเตรียมเงินไปประมาณเท่าไหร่ดี? สภาพอากาศที่กรุงปรากในช่วงเดือนธันวาคมเป็นอย่างไร? ควรเตรียมเสื้อผ้าหรือสิ่งของอะไรไปบ้าง และอะไรที่ไม่จำเป็นต้องนำไปครับ? รบกวนช่วยอธิบายรายละเอียดให้ครบถ้วนด้วยนะครับ
